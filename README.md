# Hi, I'm Tyler Clark 👋

I build full-stack web apps for iPhone, from idea to deployed product, using **Next.js, TypeScript, Supabase (Postgres) and AI**, with [Claude Code](https://claude.com/claude-code) as my AI pair programmer. I own the product decisions, test on a real phone, and ship in small pull requests with automated tests. Based in Lehi, Utah.
